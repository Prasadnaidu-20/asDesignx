# Project Instructions

## Project
DesignHub is a design marketplace for discovering, purchasing,
and submitting original designs.

## Development Rules
- Inspect existing code before making changes.
- Modify existing components whenever practical.
- Never create duplicate pages or components for small UI changes.
- Avoid unrelated refactoring.
- Preserve existing API contracts and backend functionality.
- Reuse installed dependencies.
- Follow existing naming and styling conventions.
- Keep components reusable and responsive.

## Frontend Changes
- Prefer targeted CSS changes for visual adjustments.
- Reuse existing design tokens and CSS variables.
- Preserve the existing dark theme and visual identity.
- Check desktop and mobile layouts.
- Do not add non-functional buttons or placeholder features.

## Efficiency
- Read only the files relevant to the task.
- Avoid scanning the entire repository for small changes.
- Group related changes into one implementation pass.
- Avoid lengthy explanations and repeated summaries.
- Report changed files, tests run, and any remaining issues.

## Validation
- Run the relevant build or type-check after changes.
- Do not modify unrelated files merely to improve code style.
